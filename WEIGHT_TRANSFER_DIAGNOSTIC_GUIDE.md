# Weight Transfer Diagnostic Guide

This guide helps you diagnose and fix the mesh crumpling issue in the Spoken Wardrobe weight transfer system.

## Quick Start

### Option 1: Use the Standalone Diagnostic Tool (Recommended for Initial Investigation)

1. Start the HTTP server:
   ```bash
   python -m http.server 8080 --directory static
   ```

2. Open in browser:
   ```
   http://localhost:8080/weight_transfer_diagnostic.html
   ```

3. Click **"Use Sample Meshes"** to load the body mesh, or load your own:
   - Body mesh: `/models/lowpoly_rigged_full_v1.glb`
   - Clothing mesh: Any GLB generated by Rodin API

4. Click **"Run Full Analysis"** to see diagnostic results

### Option 2: Use Diagnostic Mode in Main App

1. Apply the patch from `three_scene_diagnostic_patch.js` to `three_scene.js`

2. Run the pipeline with debug mode:
   ```bash
   python src/modules/speech_to_clothing_with_rodin_api.py --ui
   ```

3. Open browser with debug flag:
   ```
   http://localhost:8080?debug=true
   ```

4. Complete a full pipeline run and check the browser console for diagnostic output

## Understanding the Crumpling Issue

### What is Crumpling?

Crumpling occurs when the clothing mesh deforms incorrectly, appearing to:
- Collapse into a point or line
- Stretch wildly in random directions
- Disappear entirely
- Show sharp, unnatural folds

### Root Causes (in order of likelihood)

#### 1. Skeleton NOT in Rest Pose During Binding (MOST COMMON)

**Symptoms:**
- Mesh immediately appears deformed on load
- Crumpling is present before any animation
- Console shows "Skeleton NOT in rest pose" warning

**Why it happens:**
The `bind()` method computes **inverse bind matrices** from the skeleton's **current** pose. If bones have been rotated before binding, the math breaks and the mesh deforms.

**Diagnosis:**
```javascript
// Check in browser console
app.threeScene.skeleton.bones.forEach(b => {
    const isRest = b.matrixWorld.elements.every((v, i) => {
        const expected = i === 0 || i === 5 || i === 10 || i === 15 ? 1 : 0;
        return Math.abs(v - expected) < 0.001;
    });
    console.log(b.name, isRest ? 'REST' : 'POSED');
});
```

**Fix:**
```javascript
// Reset skeleton before binding
skeleton.bones.forEach(bone => {
    bone.position.set(0, 0, 0);
    bone.quaternion.set(0, 0, 0, 1);
    bone.scale.set(1, 1, 1);
});
skeleton.update();
skeleton.calculateInverses();
```

#### 2. Mesh Size Mismatch

**Symptoms:**
- Clothing is huge or tiny compared to body
- Weight transfer assigns all vertices to root bone
- Console shows "Significant size mismatch" warning

**Diagnosis:**
- Check bounds comparison in diagnostic output
- Body and clothing should be within 2x scale of each other

**Fix:**
Normalize mesh scales before weight transfer:
```javascript
const bodyBox = new THREE.Box3().setFromObject(bodyMesh);
const clothingBox = new THREE.Box3().setFromObject(clothingMesh);
const bodySize = bodyBox.getSize(new THREE.Vector3());
const clothingSize = clothingBox.getSize(new THREE.Vector3());

const scaleFactor = bodySize.y / clothingSize.y;
clothingMesh.scale.multiplyScalar(scaleFactor);
```

#### 3. Coordinate Space Misalignment

**Symptoms:**
- Clothing appears in wrong location (floating above/below body)
- Weight transfer assigns vertices to wrong bones
- Console shows "Clothing mesh is significantly offset" warning

**Diagnosis:**
- Check bounds centers in diagnostic output
- Body and clothing centers should be within ~0.5 units

**Fix:**
Align clothing to body center before transfer:
```javascript
const bodyCenter = bodyBox.getCenter(new THREE.Vector3());
const clothingCenter = clothingBox.getCenter(new THREE.Vector3());
const offset = bodyCenter.clone().sub(clothingCenter);
clothingMesh.position.add(offset);
```

#### 4. Invalid Skeleton Matrices

**Symptoms:**
- Mesh disappears entirely
- Console shows NaN errors
- WebGL warnings about invalid vertices

**Diagnosis:**
```javascript
// Check for NaN in bone matrices
skeleton.bones.forEach(bone => {
    const hasNaN = bone.matrixWorld.elements.some(v => isNaN(v));
    if (hasNaN) console.error('Bone', bone.name, 'has NaN!');
});
```

**Fix:**
Regenerate the body mesh GLB with proper bind poses in Blender:
1. Import `lowpoly_rigged_full_v1.glb` into Blender
2. Ensure all bones are in rest pose (Alt+G, Alt+R, Alt+S)
3. Export with "Use Current Pose as Rest Pose"

## Using the Diagnostic Tool

### Visualization Modes

1. **Show Weight Painting**
   - Colors vertices by dominant bone influence
   - Red = root/hips, Green = spine, Blue/Yellow/etc = limbs
   - Helps identify if vertices are assigned to correct bones

2. **Wireframe Mode**
   - Shows mesh topology
   - Helps spot degenerate triangles or irregular geometry

3. **Show Skeleton**
   - Displays bone hierarchy as lines
   - Verify bones are in expected positions

4. **Distance Heatmap**
   - Red = far from body, Green = close
   - Clothing should be mostly green (close to body surface)

5. **Normal Vectors**
   - Shows surface orientation
   - Useful for detecting inverted faces

### Running Diagnostics

Click **"Run Full Analysis"** to check:
- Mesh bounds compatibility
- Skeleton state (rest vs posed)
- Weight distribution
- Potential topology issues

### Test Deformation

Use the rotation buttons to test:
- **Rotate Left/Right Arm**: Should move sleeves, not torso
- **Rotate Spine**: Should move entire upper body
- **Reset Pose**: Returns to rest pose

If rotation causes crumpling, the weight transfer has issues.

### Good Signs ✅

✓ Size mismatch within acceptable range
✓ No degenerate triangles found
✓ No NaN values detected

## Step-by-Step Debugging

### Step 1: Verify Body Mesh

In the diagnostic tool:
1. Load only the body mesh
2. Enable "Show Skeleton"
3. Verify:
   - All 9 bones visible
   - Bones form human shape
   - No console errors

### Step 2: Test Weight Transfer

1. Load both body and clothing meshes
2. Check console output for warnings
3. Enable "Show Weight Painting"
   - Torso should be red/green (spine/hips)
   - Arms should be different colors per segment
   - No vertices should be uncolored (white/gray)

### Step 3: Test Deformation

1. Click "Rotate Left Arm"
2. Observe:
   - ✅ GOOD: Only left arm vertices move
   - ❌ BAD: Torso also moves (weight spillover)
   - ❌ BAD: Mesh crumples (bind matrix issue)

### Step 4: Export Report

In the main app with diagnostic patch:
```javascript
// In browser console
app.threeScene.exportDiagnosticReport();
```

This downloads a JSON file with full diagnostic data.

## Common Fixes

### Fix 1: Reset Skeleton Before Each Transfer

In `three_scene.js`, modify the weight transfer section:

```javascript
// BEFORE weight transfer
if (this.bodyMeshLoaded && this.weightTransfer && loadedMesh && !this.skipSkeletal) {
    // ADD THIS:
    // Reset skeleton to rest pose
    this.skeleton.bones.forEach(bone => {
        bone.position.set(0, 0, 0);
        bone.quaternion.set(0, 0, 0, 1);
        bone.scale.set(1, 1, 1);
    });
    this.skeleton.update();
    this.skeleton.calculateInverses();
    
    // Then proceed with transfer
    this.skinnedClothingMesh = this.weightTransfer.transfer(
        this.bodyMesh,
        loadedMesh
    );
    ...
}
```

### Fix 2: Normalize Mesh Scales

```javascript
// Add before weight transfer
const bodyBox = new THREE.Box3().setFromObject(this.bodyMesh);
const clothingBox = new THREE.Box3().setFromObject(loadedMesh);
const bodySize = bodyBox.getSize(new THREE.Vector3());
const clothingSize = clothingBox.getSize(new THREE.Vector3());

// Scale clothing to match body height
const scaleFactor = bodySize.y / clothingSize.y;
loadedMesh.scale.multiplyScalar(scaleFactor);
loadedMesh.updateMatrixWorld(true);
```

### Fix 3: Center Clothing on Body

```javascript
// Add before weight transfer
const bodyCenter = bodyBox.getCenter(new THREE.Vector3());
const clothingCenter = clothingBox.getCenter(new THREE.Vector3());
const offset = bodyCenter.clone().sub(clothingCenter);
loadedMesh.position.add(offset);
loadedMesh.updateMatrixWorld(true);
```

## When All Else Fails

If weight transfer continues to fail:

1. **Use Rigid Transform Fallback**
   - The system already has this - mesh will move but not deform with body
   - Add `?noskel=true` to URL to disable skeletal animation

2. **Pre-Rigged Clothing**
   - Generate clothing directly onto the body mesh topology in Blender
   - No weight transfer needed

3. **SMPL-X Approach (Path B)**
   - Use industry-standard parametric body model
   - More complex but guaranteed to work
